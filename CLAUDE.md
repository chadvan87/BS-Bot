# Binance Square Signal Studio — Claude Code notes

This file is documentation for Claude Code to help maintain and repair the project. The
app itself no longer calls Claude Code or any LLM at runtime — post copy is generated by
a deterministic Python template engine (see `app/services/post_templates.py`).

## Architecture
- FastAPI + SQLite (or Postgres/Supabase when `DATABASE_URL` is set, see `app/db.py`) + vanilla HTML/JS.
- Python scans market data, manages drafts/scheduling, and generates post copy and charts.
- `app/services/post_templates.py` — `PostTemplateEngine`, 6 deterministic categories (breaking momentum,
  trade setup, technical deep dive, reversal watch, signal update, market radar); the old 18 style names are
  aliases. No AI, no randomness, no network. Evidence-driven: reasons come from stored signal data
  (`signals.evidence` JSON), `check_post_text()` enforces banned phrases / cashtag rules.
- `app/services/market_events.py` — closed-candle breakout/retest/reversal/volume-surge detectors and
  `evaluate_path()` (candle replay that reports AMBIGUOUS instead of guessing stop-vs-target order).
- `app/services/opportunities.py` — Signal Opportunities scoring/ranking (pure functions; data is fetched
  by the browser and posted to `/api/opportunities/scan`).
- `app/services/chart_service.py` — `generate_signal_chart()`, dark-theme matplotlib
  candlestick chart with EMA20/50/200, volume + RSI panels, entry/SL/TP levels,
  support/resistance, and a LONG/SHORT badge.
- Publishing MUST use Binance's official `square-post/scripts/post-text.mjs` (text-only
  posts) or `post-image.mjs` (posts with a generated chart attached).
- Never invent or hand-code a Binance Square endpoint for normal posting.
- The `.claude/skills/binance-square-writer` skill was removed — it existed only to drive
  Claude-based post generation, which this app no longer does.

## Authentication
- UI accepts one Binance Square OpenAPI key.
- Key is stored in the database setting `BINANCE_SQUARE_OPENAPI_KEY` (SQLite locally, Postgres if `DATABASE_URL` is set).
- Every publish reads the latest key from the database and injects it only into the subprocess environment.
- Never put the key in CLI args, URLs, logs, API responses, HTML, README, or source.

## Official posting command
Run from the installed skill directory:
`node scripts/post-text.mjs --text "..."`
with environment variable `BINANCE_SQUARE_OPENAPI_KEY`.

## Safety
- Keep human confirmation for Post now.
- No CAPTCHA bypass, proxy rotation, account evasion, fake success, or infinite retries.
- On subprocess failure, preserve the draft and show the official script error.
- Scheduling is app-side; official square-post only creates new posts.
